# 💰 Expense Tracker 2.0 (Python CLI)

This is my **Task 3** of the Python internship — an enhanced Expense Tracker with **categories, search, and monthly total calculations**.

### 🚀 Features
- Add expenses with **Category** (Food, Travel, Shopping, etc.)
- **Search** expenses by category
- **View total** spent per category
- **View monthly** spending totals
- Stores data in `expenses.csv`

### 🧠 Skills Practiced
- File handling (CSV)
- Data filtering and calculations
- CLI-based menu systems
- Python datetime and CSV modules

### 🏃‍♀️ How to Run
1. Clone or download this repo
2. Run:
   python expense_tracker_2.0.py
